# TypeScript Basics

These files teach TypeScript as "JavaScript plus types." The goal is to help a learner model real data, catch mistakes earlier, and become comfortable reading typed codebases.

## How to Study

1. Finish the JavaScript fundamentals first.
2. Read one numbered file at a time.
3. Paste small snippets into the TypeScript Playground or run the practice type checks.
4. Use `practice/typescript/` for active compiler feedback.
