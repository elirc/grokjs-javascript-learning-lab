# Generated Example Archive

This folder preserves the generated repetition examples that used to live directly in `examples/`.

Nothing was deleted. The files were moved here so the top-level `examples/` folder can stay readable.

Recommended use:

1. Read the numbered lesson.
2. Complete the matching `practice/` topic if one exists.
3. Use this archive only when you want extra repetition around a concept.

The stronger worked examples live one level up in `examples/`.
