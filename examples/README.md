# Examples

This folder is for worked examples that are useful to read after the numbered lessons.

The top-level files are the higher-signal examples worth opening first:

- `advanced-closures.js`
- `advanced-promises.js`
- `example-js-array-methods-transform.js`
- `example-js-async-await-patterns.js`
- `example-js-dom-and-events.js`
- `example-js-fetch-and-error-handling.js`
- `example-js-event-loop-and-microtasks.js`
- `example-js-functions-and-defaults.js`
- `example-js-memoization-and-performance.js`
- `example-js-mutability-and-references.js`
- `example-js-promises-and-error-propagation.js`
- `example-js-proxy-and-reflect.js`

Use these when you want a fuller example with a real pattern and explanation.

## Generated Variants

The generated repetition files were preserved, but moved into `generated/` so they do not drown out the stronger examples.

- `generated/numbered-js-variants/` keeps the many numbered JavaScript variants.
- `generated/extra-pattern-variants/` keeps the extra repetition variants.

These are optional reinforcement material. Prefer `practice/` when you want tests and active recall.
