# React Basics

These files continue the same teaching style as the original JavaScript Learning Lab.

React builds on top of JavaScript. Be comfortable with arrays, objects, functions, DOM/events, and async before you go deep here.

## How to Study

1. Read one numbered file at a time.
2. Type the examples into a real React project when possible.
3. Use the matching `practice/react/` drills when you want tested feedback.
4. Pay special attention to state, effects, forms, accessibility, and testing. Those are the fastest path toward junior-level React work.
