# TypeScript Practice

These drills add feedback loops for TypeScript. Instead of runtime tests, the main feedback is the compiler.

Run from `javascript-learning-lab`:

```bash
npm run test:ts
```

Each topic has:

- `starter.ts` - implement this first
- `solution.ts` - worked solution
- `expected-output.md` - what the runtime shape should look like
- `*.type-test.ts` - compile-time expectations for the solution

Current topics:

- `narrowing`
- `generics`
