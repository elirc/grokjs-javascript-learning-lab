# TypeScript Generics Practice

Generics let you write reusable code without throwing away type safety. These drills model API responses, repositories, grouping, and `Result` helpers.

## Drills

- Preserve value types through identity helpers.
- Model API responses.
- Build typed repositories.
- Group arrays while preserving item types.
- Pluck typed object keys.
- Map success values inside `Result` objects.
