# React Practice

These drills use Vitest and React Testing Library so React lessons get the same feedback-loop treatment as core JavaScript.

Run from `javascript-learning-lab`:

```bash
npm run test:react
LAB_TARGET=starter npm run test:react
```

Each topic has:

- `starter.jsx` - implement this first
- `solution.jsx` - worked solution
- `expected-output.md` - behavior examples
- `<topic>.test.jsx` - component tests

Current topics:

- `components-props`
- `state-effects`
