# Arrays Practice

Arrays are the everyday data structure of JavaScript. These drills turn the earlier array lessons into a feedback loop: read the prompt, implement the starter, run the tests, then compare with the solution.

## How to Practice

1. Open `starter.js`.
2. Implement one function at a time.
3. Run `node practice/run-tests.js starter arrays` from `javascript-learning-lab`.
4. Check `expected-output.md` if you want examples before reading the solution.
5. Read `solution.js` only after you have tried the drills.

## Drills

- Remove values without mutating the original array.
- Split arrays into chunks.
- Move zeros to the end while keeping non-zero order.
- Find the most frequent value.
- Flatten nested arrays by hand.
- Rebuild map, filter, and reduce.
- Rotate arrays left and right.
- Group objects by a property or callback.
- Remove duplicates while preserving order.
- Find the second largest unique number.
