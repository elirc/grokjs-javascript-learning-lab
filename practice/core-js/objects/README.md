# Objects Practice

Objects are how JavaScript models most real data: users, products, settings, API responses, and state. These drills focus on copying, comparing, reshaping, and safely reading object data.

## How to Practice

1. Open `starter.js`.
2. Implement one function at a time.
3. Run `node practice/run-tests.js starter objects`.
4. Use `expected-output.md` for examples.
5. Compare against `solution.js` after you attempt the drills.

## Drills

- Deep clone plain objects and arrays.
- Deep merge nested objects.
- Read nested values using a dot path.
- Convert objects to and from query strings.
- Count objects by a property.
- Pick and omit keys.
- Compare nested values deeply.
- Convert entries to objects and back.
- Demonstrate freeze, seal, and preventExtensions.
- Safely access nested data with a fallback.
