# Functions Practice

Functions are more than reusable blocks of code. These drills cover arguments, context, higher-order functions, composition, and currying.

## How to Practice

1. Open `starter.js`.
2. Implement one function at a time.
3. Run `node practice/run-tests.js starter functions`.
4. Use `expected-output.md` for sample calls.
5. Compare with `solution.js` after attempting the drills.

## Drills

- Use `call`, `apply`, and `bind`.
- Sum numbers with rest parameters.
- Build partial application helpers.
- Create a fluent API.
- Compare regular functions and arrow functions for `this`.
- Compose and pipe functions.
- Implement `once`, `before`, and `after`.
- Build a curry helper.
