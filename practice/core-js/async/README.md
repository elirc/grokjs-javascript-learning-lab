# Async Practice

Async code is where real applications start to feel tricky. These drills build feedback loops around promises, retries, cancellation, concurrency, debouncing, and queues.

## How to Practice

1. Open `starter.js`.
2. Implement one function at a time.
3. Run `node practice/run-tests.js starter async`.
4. Use `expected-output.md` for examples.
5. Read `solution.js` after you attempt the drills.

## Drills

- Timeout wrapper.
- Sequential vs parallel task runners.
- Retry with optional delay.
- Concurrency limit.
- Promisify callback APIs.
- Cancellable operation wrapper.
- Async debounce.
- `Promise.allSettled` clone.
- Sequential reduce.
- Task queue with max concurrency.
