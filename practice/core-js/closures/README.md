# Closures Practice

Closures are functions that remember variables from the place where they were created. These drills use closures for private state, memoization, event emitters, rate limiting, and small stores.

## How to Practice

1. Open `starter.js`.
2. Implement one closure pattern at a time.
3. Run `node practice/run-tests.js starter closures`.
4. Use `expected-output.md` for sample behavior.
5. Read `solution.js` after you attempt the drills.

## Drills

- Counter factory.
- Once utility.
- Private bank account.
- Loop handler fix.
- Event emitter.
- Memoization.
- Rate limiter.
- Currying.
- Validated private temperature state.
- Closure-backed todo store.
