# DOM and Browser Practice

These drills practice browser APIs with automated tests through `jsdom`. That means learners get feedback on DOM code without needing to open a browser for every small exercise.

## How to Practice

1. Open `starter.js`.
2. Implement one function at a time.
3. Run `node practice/run-tests.js starter dom-browser`.
4. Use `expected-output.md` for sample behavior.
5. Compare with `solution.js` after you attempt the drills.

## Drills

- Create DOM elements with text, classes, attributes, and dataset values.
- Delegate events from a container to matching children.
- Dispatch custom browser events.
- Read form data into an object.
- Validate required form fields.
- Debounce and throttle event handlers.
- Store JSON in localStorage with expiry.
- Track online/offline events.
- Copy text through the Clipboard API with a fallback.
